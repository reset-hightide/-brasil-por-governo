# Brasil por Governo, 1979–2025

🇧🇷 **Painel comparativo de dados anuais.** Trinta e três indicadores em dez temas, mais o ranking do Brasil entre as maiores economias do mundo. O fundo de cada gráfico identifica o presidente em exercício, e a tabela no fim mostra quanto cada indicador mudou do início ao fim de cada mandato.

🇺🇸 **Comparative dashboard of annual data.** Thirty-three indicators across ten themes, plus Brazil's rank among the world's largest economies. Each chart's background identifies the president in office, and the table at the end shows how much each indicator changed from the start to the end of each term.
